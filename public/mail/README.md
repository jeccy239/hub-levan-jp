# メール用画像の置き場

ここに置いたファイルは `https://hub.levan.jp/mail/<ファイル名>` で配信されます。
コミットしてデプロイした時点で有効になります。

HTMLメールからは必ず**絶対URL**で参照してください。メールソフトは相対パスを
解決できないため、`/mail/logo.png` のような書き方では表示されません。

## テンプレートが参照しているファイル

| ファイル名 | 用途 | 推奨サイズ |
|---|---|---|
| `logo.png` | ヘッダー帯のロゴ | 高さ 64px（表示は32px。Retina対応で2倍） |
| `hero.png` | 本文上部のバナー | 幅 1200px（表示は600px。同じく2倍） |

表示サイズの2倍で作るのは、高解像度ディスプレイでぼやけないようにするためです。

## 注意

- **多くのメールソフトは既定で画像をブロックします。** 重要な情報（日付、金額、
  CTAの文言）を画像内だけに置かないでください。画像が出ない状態でも意味が
  通る本文にしてください。
- 画像が多いHTMLメールは迷惑メール判定を受けやすくなります。特に新規開拓では
  テキスト形式の方が届きやすい傾向があります。
- 1ファイルは 1MB 以下を目安に。重い画像は読み込まれずに終わります。
