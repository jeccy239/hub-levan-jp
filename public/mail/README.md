# メール用画像の置き場

ここに置いたファイルは `https://hub.levan.jp/mail/<ファイル名>` で配信されます。
コミットしてデプロイした時点で有効になります。

HTMLメールからは必ず**絶対URL**で参照してください。メールソフトは相対パスを
解決できないため、`/mail/logo_01.png` のような書き方では表示されません。
（この理由で、ローカル開発中のプレビューでは本番にデプロイ済みの画像だけが
表示されます。）

## 現在使っているファイル

| ファイル | 用途 | 寸法 | 使っているテンプレート |
|---|---|---|---|
| `logo_01.png` | ヘッダー帯のロゴ | 350×64（表示175×32） | HTML全テンプレート |
| `hero_01.jpg` | SEO分析バナー | 1200×800（表示600×400） | 新規開拓（WEBRIS訴求） |
| `hero_02.jpg` | ヒートマップバナー | 1200×800（表示600×400） | 新規開拓（ヒートマップ訴求） |

表示サイズの2倍で作っているのは、高解像度ディスプレイでぼやけないようにするためです。

`hero_01.png` / `hero_02.png` は元データです。メール配信には**使っていません**
（PNGのままだと1枚900KB前後あり、メールには重すぎるため、同じ絵をJPEGに変換した
`.jpg` を配信しています。画質の劣化は目視できないレベルで、容量は約1/5です）。
差し替える場合も、PNGを置いたうえで JPEG に変換してから参照してください。

    sips -s format jpeg -s formatOptions 72 hero_01.png --out hero_01.jpg

## 注意

- **多くのメールソフトは既定で画像をブロックします。** 重要な情報（日付、金額、
  CTAの文言）を画像内だけに置かないでください。画像が出ない状態でも意味が
  通る本文にしてください。バナー内の「SEO分析／競合調査／改善提案」といった
  文言も、本文側に書いておく必要があります。
- 画像が多いHTMLメールは迷惑メール判定を受けやすくなります。特に新規開拓では
  テキスト形式の方が届きやすい傾向があります。
- 1ファイルは 200KB 程度を目安に。
